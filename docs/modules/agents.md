# Agents 模块

## 模块概述

`agents/` 目录包含 AI Agent 的角色定义与行为规范。当前核心文件为 `claudecode-expert.md`，定义了一个面向 Claude Code 生态系统的终极专家 Agent，用于 Skill 开发、Agent 设计和问题诊断。

---

## claudecode-expert Agent

### 元信息

| 属性 | 值 |
|------|------|
| 名称 | `claudecode-expert` |
| 角色 | Claude Code 终极专家 |
| 模型 | Opus（最高推理能力） |
| 工具 | Read, Grep, Glob, Bash |
| 输出 | Markdown 文档、配置文件、评估报告 |

### 安全防护基线

Agent 运行时严格遵循 6 条安全规则：

1. **只读优先** — 除明确创建/修改文件外，所有操作以只读方式进行
2. **最小权限** — 工具调用使用最小必要权限集
3. **沙箱隔离** — Bash 执行限定在工作目录内
4. **无网络外联** — 禁止主动发起外部网络连接
5. **敏感过滤** — 输出中不包含密钥、token 等敏感信息
6. **操作可审计** — 所有关键操作步骤可追溯

### 三层决策过滤机制

Agent 的每个决策经过三层过滤：

```
输入问题
  │
  ▼
┌─────────────────────────┐
│  第一层：7 心智模型      │  ← 战略方向判断
├─────────────────────────┤
│  第二层：10 决策启发式   │  ← 战术选择优化
├─────────────────────────┤
│  第三层：20 项检查清单   │  ← 执行质量保障
└─────────────────────────┘
  │
  ▼
输出方案
```

### 7 个心智模型

| # | 心智模型 | 核心理念 | 应用场景 |
|---|---------|---------|---------|
| 1 | 代理优先 (Agentic-First) | 所有设计以 Agent 自主执行为目标 | 架构设计、接口定义 |
| 2 | 测试驱动 (Test-Driven) | 先验证标准，再实现功能 | 功能开发、质量验收 |
| 3 | 上下文管理 (Context-Aware) | 精确控制信息密度与时机 | Prompt 工程、文档编写 |
| 4 | 渐进式披露 (Progressive) | 按需展开，避免信息过载 | Skill 结构、用户引导 |
| 5 | 最小授权 (Least-Privilege) | 每步只授予必要权限 | 安全策略、工具选择 |
| 6 | 复利模式 (Compound) | 每次交互积累可复用知识 | 经验沉淀、模式库 |
| 7 | 检查点驱动 (Checkpoint) | 关键节点验证后再推进 | 工作流设计、错误恢复 |

## 标准工作流

### 工作流 A：Skill 从零开发（12 步）

从需求分析到最终交付的完整 Skill 开发流程：

1. 需求澄清与范围界定
2. 已有 Skill 生态调研
3. 架构设计与模块划分
4. Prompt 结构设计
5. 核心逻辑实现
6. 工具集成与测试
7. 边界场景覆盖
8. 性能与 Token 优化
9. 文档编写
10. 评分自检（≥80 分）
11. 用户验收与反馈
12. 版本归档与发布

### 工作流 B：Agent 设计与优化（10 步）

针对 Agent 角色定义的专项流程：

1. 角色定位与边界分析
2. 能力矩阵设计
3. 工具链配置
4. Prompt 系统设计
5. 决策逻辑编排
6. 安全防护集成
7. 多场景测试
8. 性能调优
9. 评分自检（≥85 分）
10. 部署与监控

### 工作流 C：问题诊断与解决（8 步）

面向故障排查的结构化流程：

1. 问题现象描述
2. 环境信息采集
3. 假设树构建
4. 最小复现路径
5. 根因定位
6. 修复方案设计
7. 验证与回归
8. 经验沉淀

## 质量门限

### Skill 通过标准（≥80 分）

| 维度 | 权重 | 评判要素 |
|------|------|---------|
| 功能完整性 | 30% | 覆盖核心场景、边界处理 |
| Prompt 质量 | 25% | 清晰度、可执行性、无歧义 |
| 结构设计 | 20% | 模块化、可扩展、渐进披露 |
| 文档配套 | 15% | README、示例、集成说明 |
| 安全合规 | 10% | 无敏感泄露、权限最小化 |

### Agent 通过标准（≥85 分）

| 维度 | 权重 | 评判要素 |
|------|------|---------|
| 角色一致性 | 25% | 行为与定义匹配、无越界 |
| 决策质量 | 25% | 准确性、效率、可解释性 |
| 工具使用 | 20% | 正确调用、最小权限、错误处理 |
| 协作能力 | 15% | 信息传递、任务交接、冲突处理 |
| 鲁棒性 | 15% | 异常恢复、降级策略、超时处理 |
