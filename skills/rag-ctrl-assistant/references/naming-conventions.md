# 卡片文件命名规范

> 目的：确保 Wiki 链接 `[[目标标题]]` 能正确匹配到文件名，避免断链。

## 核心规则

**文件名 = Wiki 链接的 slug 形式**，公式：

```
文件名 = 标题（中文保持原样，英文用小写 + 连字符）
链接slug = 标题.lower().replace(' ', '-')
匹配条件 = 文件名.stem == 链接slug
```

| 张三 - 复仇的金融天才 | `character-张三.md` | `张三---复仇的金融天才` | ❌ |

## 解决策略

**二选一，选定后全局遵守：**

### 方案A：中文文件名（推荐用于中文内容库）

文件名直接用标题去除特殊字符：
- `观察者模式.md` / `移动平均线交叉策略.md` / `张三角色卡.md`

优点：链接和文件名直观一致，`[[观察者模式]]` 自然匹配 `观察者模式.md`
缺点：长标题文件名略长

### 方案B：slug 文件名 + frontmatter alias

文件用英文 slug，在 frontmatter 中添加 alias：
```yaml
---
alias: "观察者模式"
---
```

然后 build.py 需修改链接匹配逻辑，支持 alias 解析。

修复步骤：
1. `git mv` 重命名文件
2. 更新其他卡片中指向旧文件名的链接
3. 运行 `build.py` 验证链接解析
4. Git 提交

## 新建卡片规范

```
规则1：文件名 = 标题去除冒号、问号等非法字符，保留中文
规则2：领域目录决定分类，文件名不重复领域名
规则3：链接 `[[目标标题]]` 中的标题必须与目标文件的标题完全一致
规则4：创建卡片后立即运行 build.py 验证链接无断链
规则5：冒号 → 全角"："或删除；斜杠 → 全角"／"或删除
```
